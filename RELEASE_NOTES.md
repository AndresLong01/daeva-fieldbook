# Daeva Fieldbook 1.0.6

- Added Battlefield to the general timer bar with overlay pinning. It uses the
  reported NA West daily windows of 11am–2pm and 8pm–10pm Pacific, including
  daylight-saving changes. This is a schedule countdown, not live server status.
- Added Alerts settings with independent 5-minute, 3-minute, 1-minute, and
  30-second checkboxes, notification volume, and a sound test. Select any
  combination or none. Existing users keep the one-minute default.
- Alert selections save automatically. Each enabled interval plays once per
  event, and missed intervals after a late start are combined into one sound.
- Fixed overlay input recovery after hiding, showing, and resizing. Unlock
  controls account for window zoom, and interrupted drag/resize gestures clear
  automatically instead of leaving stale input state.
- The general timer bar wraps to fit smaller windows.

Existing notes, goals, pins, and saved preferences are retained. Use Settings →
Check for updates, then Download update beside the title to install this release.
