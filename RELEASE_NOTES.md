# Daeva Fieldbook 1.0.7

- Gathering goals now fade to “Complete!” when reached, then fade out and are removed from the active list automatically. The gathering overlay closes when its last goal finishes. Correcting a count below the target cancels completion.
- Removed the add-one gathering keyboard shortcut and its settings control. Manual plus/minus buttons remain available in the goal list.
- Removed the “Drag” text from overlay headers.
- Overworld Bosses, Abyss, and pinned timer overlays use consistent soonest-first ordering: active or due items first, upcoming timers next, and unknown times last. Lists update automatically while retaining the selected target.

Existing notes, active goals, timer pins, and other saved preferences are retained. Use Settings → Check for updates, then Download update beside the title to install this release.
