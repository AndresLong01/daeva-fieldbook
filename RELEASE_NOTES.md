# Daeva Fieldbook 1.0.3

- Added a Hidden Cubes tab with 2,811 bundled locations across Verteron and
  Altgard, using the full offline game maps.
- Search and filter cubes by subregion, focus on one area, or show all locations.
  Locations outside mapped subregion boundaries remain available in their own group.
- Pan, zoom, fit the visible locations, adjust pointer sizes, and toggle teleport
  statues. Map and filter preferences are saved between sessions.

Existing notes, goals, pins, and saved preferences are retained. Use Settings →
Check for updates, then Download update beside the title to install this release.
